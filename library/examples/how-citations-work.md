# How citations work in Interview Prep Tool

Every claim in an answer ends with a tag that says where it came from.

## The four tags

- **local** points to a passage in one of your own papers or notes, with the page number for PDFs.
- **code** points to project code, with the file and line range. Code is only sent to a model after you pick the provider.
- **web** points to a page found by web search. Open the link before relying on it.
- **model knowledge** means the claim has no source. It comes from what the model already knew, so treat it as a lead to check.

## What a tag does and does not prove

The tool checks that the cited source exists and that the page or line range is real. It cannot check that the source
supports the claim. Read the passage in the Evidence column for anything important.
